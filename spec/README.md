## Component map

```
crm/
├── lens-svc/        Spring Boot 3 backend  (JWT auth, JPA, REST :8080)
├── lens-ui/         React 19 + Vite + Tailwind v4 + shadcn/ui  (:3000)
├── start.bat/.sh    one-command local run
├── spec/            ← this documentation
└── ai-agent-workflow/  internal process docs (gitignored)
```

## Business chain at a glance

```
Customer → Sales Inquiry (items) → Quotation → Order Forwarding Memo (OFM)
                                        ↕
                Sales Inquiry item → DRF (PumpSeal / RotaryJoint / APIPlan / AgitatorSeal)
                OFM → OFM Communications (activity history + attachments)
```

Every entity has a `*ReferenceNo` business key generated by `SalesInquiryIdSequence`
(`SAL/`, `CUST/`, `/PUM/`, `/AGT/`, `/API/`, `/ROT/`, `Q/`, `OFM/` prefixes).
